# CK3 government category + the country's EU5 religion -> EU5 government setup.
# gov: converted category (monarchy/republic/theocracy/tribe/horde), derived from the CK3 government string.
# religion: one or more exact EU5 religions this link serves. Beats a religion_group link.
# religion_group: EU5 religion group; links with neither religion nor group are the category fallback.
# template: main_menu/setup/templates file to include.
# type: the EU5 government type the template expects (mismatches make the game reject the template's laws).
# parliament: parliament_type matching the template, written explicitly so the engine never complains.
# heir: default heir_selection; CK3 succession laws override it where mapped.
# tech: starting_technology_level, used only when the realm's own innovations give no better estimate.
#
# Templates carry laws and privileges the engine gates on religion, and it strips any that don't
# apply at load. The gates that matter here:
#   patriarchate_law      - orthodox, strigolniki, miaphysite only
#   iqta_law, muslim_marriage, freedom_of_interpretation, efficient_tax_farming - muslim group only
#   clergy_land_rights    - everyone EXCEPT the christian group
#   civil_law_policy      - christian group, or a capital in Europe
#   polygyny              - pagan faiths, hindu, or an Indian culture
#   legal_code_law        - any non-tribal government, or a muslim one
# Pick templates whose content clears those gates for the religion in question.

### Monarchies
# The eastern european template is built around patriarchate_law, so it belongs to the Orthodox family.
link = { gov = monarchy religion = orthodox religion = strigolniki religion = miaphysite religion = nestorianism religion = paulicianism religion = bogomilism
	template = eastern_european_monarchy type = monarchy parliament = estate_parliament heir = cognatic_primogeniture tech = 3 }
# Western Christendom: civil law and the powerful-dioceses privileges instead of clergy land rights.
link = { gov = monarchy religion_group = christian template = catholic_monarchy type = monarchy parliament = estate_parliament heir = cognatic_primogeniture tech = 3 }
link = { gov = monarchy religion_group = muslim template = muslim_monarchy type = monarchy parliament = council heir = cognatic_primogeniture tech = 3 }
link = { gov = monarchy religion_group = buddhist template = east_asia_monarchy type = monarchy parliament = council heir = cognatic_primogeniture tech = 3 }
link = { gov = monarchy religion_group = dharmic template = indian_hindu_monarchy type = monarchy parliament = council heir = cognatic_primogeniture tech = 3 }
# Everyone else - Jewish, Zoroastrian, Manichaean, Yazidi, Mandean and every folk faith. This
# template's laws are religiously neutral (traditional legal code, monogamy, any-religion heirs).
link = { gov = monarchy template = subsaharan_monarchy type = monarchy parliament = assembly heir = cognatic_primogeniture tech = 2 }
