# CK3 realm laws and cultural pillars -> EU5 government effects.
#
# The country's societal values start from its setup template's own numbers. Realm laws then set
# values outright (a realm with crown authority III is centralized, whatever its template thought),
# and the culture's ethos and traditions nudge them from there. Everything is clamped to -100..100.
#
#   value     = { ck3 = <ck3 law>       key = <eu5 societal value> offset = <absolute position> }
#   ethos     = { ck3 = <ck3 ethos>     key = <eu5 societal value> shift = <relative shift> }
#   tradition = { ck3 = <ck3 tradition> key = <eu5 societal value> shift = <relative shift> }
#   heir      = { ck3 = <ck3 law fragment> eu5 = <eu5 heir_selection> }
#
# An ethos or tradition link may carry several key/shift pairs. Heir fragments match by substring;
# the first match in file order wins.
